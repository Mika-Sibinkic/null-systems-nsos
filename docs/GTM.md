## Wedge pain (the burning thing)
The diagnostic must hit a pain the operator will pay to quantify. Hypotheses to validate with design
partners: proposal/sales-cycle drag, silent retention loss, over-scoped/duplicated tooling spend,
leadership hours sunk in coordination. **Validate which one is the wedge before going wide.**

  hands-on FDE follow-through; we get real messy data + labeled outcomes.
- These partners double as the **eval-set cold-start** (see below) and the first realized-outcome
  data points for the flywheel.

<a id="eval"></a>
## Eval set = crown-jewel IP (Karpathy)
The labeled diagnostic "signaling" — which findings were real, which SOWs the operator picked, which
delivered — is the asset competitors can't copy. **Cold-start:** bootstrap labels from Null Systems'
**prior consulting engagements** before live clients exist; expand with every design-partner outcome.
Version it; treat it as IP, not a byproduct.

<a id="trust"></a>
## Trust as sales collateral (LeCun + compliance pillar)
SMB handing over financials is the biggest activation barrier. Make trust a feature:
- "**We don't train shared models on your data**" — guaranteed by NIM-primary (no client data to a
  frontier vendor) + per-tenant isolation.
- **DPA** ready to sign; **SOC2** path on the roadmap.
- Surface this on the marketing site + onboarding, not buried in a compliance page.
