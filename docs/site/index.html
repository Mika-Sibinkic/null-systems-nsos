1 · Seamless onboarding

Operator connects existing infra (accounting/ERP, CRM, comms). Secrets stored server-side only; the web holds a scoped short-lived token. Each source is read via a provider adapter and snapshotted to client/snapshots/{tenant_id}/baseline.json. A <1h teaser surfaces one high-signal finding to hook the operator while the full run proceeds async.

2 · The diagnostic (6 meta-teams → quantified findings)

Six teams (financial, operational, organizational, customer, technology, strategic) each run a gauntlet of executive-grade questions against the snapshot, producing findings with quantified impact_usd / impact_hours / bottleneck. Every number traces to source data (invoice line, timesheet, CRM event, benchmark) + a confidence band — the LLM narrates, the math computes. Below-threshold findings route to FDE review before the client sees them (autonomy slider).

3 · Council ranking

Findings reconvene in a council weighted by recursive context — alignment with the CEO's stated priorities, novelty vs known baseline, cross-team corroboration, projected $/hours impact. Pairwise LLM-judge tournament + debate, not scalar scoring. Works today.

4 · Two or three scored SOWs (the decision bridge)

Ranked findings bundle into 2–3 coherent SOW candidates. Each is scored by the bridge: WWMD predicts whether a Null Systems consultant would push it (+ confidence + gaps); the 5-pillar engineering bar grades deployability. Each SOW carries quantified success metrics (EBITDA +X%/yr, N hrs/yr, payback M months) so the operator chooses on evidence + their own sense of priority.

Outcome flywheel — the moat

Predicted vs realized impact per shipped SOW feeds back, compounding diagnostic accuracy and powering a monitoring/recurring tier (land-and-expand). Anyone can call an LLM; nobody else has the realized-outcome dataset. The eval set / consulting signaling is versioned as crown-jewel IP, cold-started from Null Systems' prior engagements.
